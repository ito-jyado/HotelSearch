Nuxt Full-stack App

宿泊施設検索アプリ

エリアや位置情報などの条件から宿泊施設を探し、一覧で確認できるWebアプリケーションです。 Nuxtのサーバールートを介して検索結果を取得し、入力エラーや0件結果も分かりやすく扱います。

概要を見る リポジトリを見る

Features

主な機能

このアプリでできることを、初めて見る人にも伝わるように整理します。

条件検索

エリアコードや緯度経度、検索範囲を指定して、目的地に合う宿泊施設を検索できます。

一覧表示

取得した施設情報を、名称・エリア・最大人数・説明などの項目に整理して表示します。

状態ハンドリング

入力エラー、取得失敗、利用制限、0件結果を区別し、次の操作が分かる状態で案内します。

How it works

使い方

検索条件の入力から結果確認までを、シンプルな流れで進められます。

  1. Step 1検索画面を開きます。
  2. Step 2エリア、位置情報、ページ、並び順などの条件を指定します。
  3. Step 3検索結果の宿泊施設一覧や0件メッセージを確認します。

Technology

技術構成

Nuxtのフルスタック構成で、画面とサーバーAPIを同じプロジェクト内にまとめています。

Nuxt Vue TypeScript npm

このアプリを試してみる

ローカル環境では npm install のあと、npm run dev で検索アプリを起動できます。
